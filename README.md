# music-theory

Spelled pitches, intervals, keys and scales, meter and rational time, transposition and respelling, a chord-symbol grammar with dialects, Roman numerals, and key detection. Pure Common Lisp, no dependencies.

**Status:** skeleton (0.0.1). The design is in the capability brief [cl-stack/docs/capabilities/music-theory.md](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/music-theory.md). The API and tests land through contract branches and team-solve.

```sh
cl-repo test --system music-theory
```
